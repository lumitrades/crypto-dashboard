# Lumi Trades: growth roadmap

A prioritized backlog for the nightly improvement job. Work **top to bottom**: pick the first unchecked item that fits in one night, ship it (test desktop + mobile, bump `?v=`, push, verify live), tick it here with the date and commit, and add follow-ups as new items. Keep the standing rules from the README: static site, no secrets, backward-compatible `data/*.json`, paper trades only, cite nothing unverified, nothing posted to X without approval, never mention the owner or personal holdings on the site.

Priority key: **P1** = biggest traffic/trust win for the effort, **P2** = solid, **P3** = nice to have / bigger bets. (The Done list below is mostly from the earlier crypto-dashboard era.)

## Guardrails for the nightly job
- One or two focused changes per night, always shippable; never break `data/*.json` contracts or the publish.sh / track_trades.py / signals.py jobs.
- No account sign-ups, payments, outreach or X posts without the owner's explicit approval. Draft them instead.
- Every number or claim on a new page must come from the data files or a verified source.
- Generated files (coin pages, `trades/`, `sitemap.xml`, the marked blocks in index.html) are rewritten by build_pages.py: change the generator, not the output.
